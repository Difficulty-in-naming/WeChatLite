# 文档入口

| 要做什么 | 唯一入口 |
|---|---|
| 用户在本机 Windows 虚拟机测试新版本 | [本机测试步骤](TEST-SERVER-STEPS.md)；共享目录里的 `使用说明.md` 是它的自动同步副本 |
| 助手编译、验证代码、把新程序放到共享测试目录 | [构建与交付](LOCAL_TESTING.md) |
| 阅读图片等媒体后台下载的实现与边界 | [后台媒体下载](BACKGROUND_MEDIA.md) |
| 日常使用客户端、服务端 | [客户端](CLIENT.md)、[服务端](SERVER.md) |
| 连接公网入口、构建正式发布包 | [P2P](P2P.md)、[发布](RELEASE.md) |

“本地测试”“本机测试”“我的测试”统一指用户在本机 Windows 虚拟机运行真实微信和服务端、配合真实客户端的手工测试。助手的单测、fixture、demo 和探测脚本只称“代码验证”。正式服务端在远处，由他人在其电脑运行。

维护规则：操作流程只在对应入口维护，不再新增 handoff 或按问题复制一份测试步骤。共享测试目录由 `scripts/stage-windows-test.py` 同步，不能手工维护另一套使用说明。候选修复、代码验证通过、本机手测通过、远端确认修复必须分别陈述。
