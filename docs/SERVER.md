# 微信轻聊转发服务端

在已登录微信的 Windows 电脑运行单文件 `WeChatLite-Server-Windows-x64.exe`；首次运行会校验并释放运行依赖到当前用户缓存。它有独立管理窗口，负责 Rust 转发核心和本机微信适配器；客户端不负责启动或停止它。原配置、凭据、授权群及数据目录独立于程序缓存保留。

1. 保持本机微信登录。当前 Windows 适配器对应微信 4.1.15.13，版本不匹配会明确停止接入。
2. 点击“设置 → 连接与存储”。只在本机使用时监听 `127.0.0.1`；其他电脑连接时监听 `0.0.0.0`，选择端口，并生成自签名证书或设置自己的 TLS 证书和私钥。服务端需要允许该端口通过防火墙。
3. 点击“启动服务”，在“转发群”页读取、勾选并保存需要转发的群。新增群默认不转发。
4. 在“客户端权限”页点击“新建客户端”，填写名字、勾选可见群，设置是否允许发送/撤回及下载。新建默认没有任何群或发送/下载权限。
5. 创建后复制客户端连接信息给对应电脑。之后可随时在“客户端权限”中选中客户端，点击“复制连接信息”再次打开；“显示密钥”可查看原文，关闭窗口或重启服务后仍可使用。复制窗口可选择正确网卡的地址，客户端也可填写可达的域名。

客户端密钥保存在服务端本机数据目录，只有本机管理员接口可以读取，普通客户端和公网 P2P 入口不能查询。旧版只保存摘要的密钥，会在原客户端用它重新连接成功后自动补存，无需更换群或权限。无法取得旧密钥时，可以点击“更换密钥”：客户端身份、名称和权限不变，但原密钥立即失效，需要在对应客户端粘贴新的连接信息。永久撤销同时删除可读取的密钥，不能通过复制或更换恢复。

实际可见群是“全局转发群”和“客户端授权群”的交集。取消群、停用客户端或永久撤销密钥立即生效；历史、成员、媒体、上传、下载、实时推送及重连重放都受权限限制。已下载到其他电脑的文件不会被远程删除。

本机管理员密钥只允许实际 TCP 回环连接，不能在其他电脑使用。独立客户端密钥即使从本机连接也不能管理群、客户端或停服。不要把管理员配置文件发给客户端。

修改连接配置前会确认并停止服务，保存后需重新启动。群与客户端权限无须重启。关闭管理窗口会收起到服务端托盘，继续转发；“停止服务”或托盘“停止服务并退出”会优雅停止由此窗口启动的进程。

“设置 → 检查更新”在服务运行时也能打开。点击检查后，有新正式版本会自动从本项目 GitHub Release 下载对应系统的服务端包，显示进度并验证大小和 SHA-256。关闭更新窗口后继续下载，退出应用则取消未完成任务。下载完成后点击“打开下载目录”，停止服务并退出，再用新 EXE 或 DMG 内的应用替换原程序；原数据目录、接入密钥和权限独立保留。

跨公网自动连接：先在自有公网服务器部署独立入口，放行入口的 TCP 与 UDP 端口。在微信所在电脑停止服务，打开“连接与存储”中的“自动连接”，粘贴部署时生成的完整入口 JSON、启用自动连接并保留 TLS 证书和私钥，再保存启动。微信电脑可以继续仅监听 `127.0.0.1`；专用客户端入站不开放管理员操作。设备 ID 保存在数据目录对应的私钥中，重启不变，不要删除或分发 `p2p.key`。

启用后，新建客户端时可复制“自动连接（直连优先）”信息，远程客户端不需要填写微信电脑的 IP。既有客户端密钥和授权群继续有效；切换连接方式不需要新建或撤销业务密钥。入口接入凭据与业务密钥分开管理，SSH 私钥不进入应用或邀请信息。更多部署、网络与加密边界见源码中的 `docs/P2P.md`。

连接信息窗口会按模式分别显示公网中转地址或局域网直连地址。自动连接时点击“修改中转设置”，可直接进入自动连接页修改 HTTPS 公网中转地址；服务运行时会先确认并停止，保存后重新启动生效。原客户端密钥、群和权限不变，之后重新复制连接信息给客户端。只修改地址会保留当前入口凭据、CA 和 QUIC 端口；换成使用不同凭据或证书的入口时，请粘贴完整公网入口信息。不要把中转地址填入局域网直连框，两者使用的连接协议不同。

首次启动可导入旧合并版的本机服务配置，保留数据目录和已选群，旧文件不删除。当前配置路径在“服务状态”页显示。聊天记录、凭据、证书私钥及个人数据不随发布包分发。

Windows 服务的单 EXE 内置 Qt 管理窗口、Rust 核心和本机适配器依赖，在当前用户缓存中按版本释放。客户端单独分发；不需要把服务端内部文件发送给客户端。

Mac 服务端 DMG 内是一个“微信轻聊服务端.app”，包含管理 GUI、转发核心与 P2P 模块。Mac 本机微信适配器尚未实现，因此此包目前不能直接转发本机 Mac 微信。Mac 客户端可以连接 Windows 微信服务端。
