# 微信轻聊客户端

Windows 直接运行单文件 `WeChatLite-Client-Windows-x64.exe`；首次运行会校验并释放运行依赖到当前用户缓存，原配置与下载目录独立保留。Mac 打开 DMG 后，将“微信轻聊.app”拖到应用程序目录再运行，依赖已收在应用内部。客户端可以运行在另一台电脑，不需要安装微信或转发服务端；关闭客户端不会停止服务器。

1. 从服务端管理员取得此客户端专用的连接信息。
2. 首次打开会显示“连接与下载设置”。粘贴服务端复制的 JSON，点击“粘贴连接信息”；或手动填写服务器 URL、客户端接入密钥、证书指纹。
3. 填写显示名和下载目录后保存。文件按 `下载目录/YYYY-MM-DD/` 保存。
4. 只显示管理员允许此客户端查看、且服务端已勾选转发的群。没有发送或下载权限时相应操作禁用；停用密钥会立即断开连接。

“自动连接”直接粘贴管理员提供的完整 JSON，客户端通过固定设备 ID 和自建公网入口找到微信所在的服务端，优先直连、失败时使用加密中继。无需填写微信电脑的公网 IP 或配置其路由器端口。内置的 `wechat-link` 只管理客户端自身的连接，退出时一同停止，不需要另外分发。

选择“直接地址”连接其他电脑时，使用 HTTPS 和服务器实际可达 IP，不能填写 `0.0.0.0` 或服务器的 `127.0.0.1`。两种方式都核对服务端 SHA-256 证书指纹和独立客户端密钥。不要使用或分发本机管理员密钥。客户端设置以后从系统托盘打开。

拖拽或粘贴文件、图片、视频、GIF 后可发送；输入 @ 选择成员。右键消息可复制、引用；原生引用当前仅支持已确认的同群文本来源。撤回是否可用由服务端能力决定，撤回后可重新编辑本客户端保留的草稿。

当前微信版本的后台撤回暂不可用，服务端会明确报告此限制，客户端禁用撤回操作。程序不会因此把原版微信切到前台或切换会话。请在原版微信中手动撤回；已提交但尚无数据库确认的旧请求保持不确定，不会重复提交。

回车发送，Shift+回车换行。中文输入法候选字和 @ 成员列表出现时，回车先确认当前选择。本机微信或服务器未连接时，发送按钮不可用，草稿继续保留，连接就绪后自动恢复。

搜索框左侧的齿轮打开“设置”。存储页可修改下载位置、查看已保存文件和缓存的用量、清理自动预览与语音缓存，并选择 256 MiB、512 MiB、1 GiB 或 2 GiB 的缓存上限，默认 512 MiB。已保存文件不会随缓存清理删除，正在显示或播放的缓存会暂时保留。修改位置只影响后续保存，不移动已有文件；新文件继续按天归档。统计和清理在后台执行。

外观页提供“跟随系统、浅色、深色”。通知页可开启或关闭新消息提示音，并试听系统提示音。点击保存后生效；提示音遵循群的三档通知设置，关闭声音仍保留允许的系统通知。

窗口启动、换屏或屏幕缩放变化时会按系统可用区域调整，不再以固定大窗口打开；较小的逻辑屏幕会自动使用紧凑文字。拖动输入框上沿可调整输入区高度，无附件时可缩到约 100 个逻辑像素，附加文件后会留出预览所需空间。松手后保存，下次启动继续使用。聊天气泡中的文字可拖选，按 Ctrl+C（Mac 为 Command+C）或右键“复制”复制选中的部分；没有选中文字时保留整条复制。

更新页点击“检查更新”，有新版本时自动从本项目 GitHub 正式 Release 下载对应系统的客户端包，显示下载进度，并验证大小和 SHA-256。可以取消或重试；关闭设置后继续下载，退出客户端则取消未完成任务。完成后点击“打开下载目录”：Windows 退出客户端后，用新 EXE 替换原 EXE；Mac 打开 DMG，将应用替换到应用程序目录。连接设置与聊天数据继续使用原用户目录。没有新版本时显示“当前已是最新版本”。

更新下载遵循本机系统代理设置，使用独立网络连接，不读取聊天密钥，也不改变聊天或 P2P 的代理配置。

常见微信方括号表情（例如 `[發][红包][凋谢][菜刀][炸弹][便便]`）会显示为对应表情；未知别名保留原文。显示转换不修改复制内容、引用数据或发送给微信的文本。

向上滚动会按需从服务端所在电脑的微信读取更早记录，补入时保持当前阅读位置；向下回到末尾可返回最新消息。消息列表最多保留 300 条，继续翻页仍可查看更早内容。引用预览与发送按钮位于输入框底部同一行。客户端不显示操作通知条；发送状态仍显示在对应消息旁。

右上角的聊天记录 SVG 图标打开独立的搜索窗口。可按关键词、文件、图片与视频、链接、语音、日期或群成员查找，每次最多读取 50 条、窗口保留最近加载的 200 条。某页没有匹配结果时可点击“继续查找”读取更早记录；不会在后台自动遍历全部历史。点击结果会回到聊天原文，媒体沿用系统应用或聊天内语音播放。

“群公告”读取转发服务端本机微信中的公告，显示发布人、更新时间和只读正文，链接使用系统浏览器打开。明确没有公告时显示“尚未设置”，缺少本机数据或读取失败时显示“暂不可读”，可重新读取。切换群、断线或撤销权限时，两个窗口都会关闭，旧请求不会恢复已经关闭的内容。

右键群可“置顶/取消置顶”，并在三个互斥通知选项中选择：忽略通知、仅被 @ 时通知、所有新消息通知。默认所有新消息通知，设置按当前连接身份保存，重启后继续生效。仅被 @ 时匹配服务端本机微信账号的真实成员 ID，或结构化的 @所有人；不会通过昵称或文本里的 @ 字样猜测。通知同样适用于当前正在浏览的群；历史补载、断线重放、重复事件、状态更新和自己发送不弹通知。忽略通知只关闭弹出，不停止接收或转发。点击通知打开对应的获准群，已撤销授权的群不会恢复显示。macOS 首次需要通知时申请系统权限；系统勿扰模式或拒绝权限时不会弹出自绘替代通知。

每条消息使用唯一的通知标识，因此同一群的新消息会重新弹出并播放提示音，而不是静默替换上一条；同群消息按会话线程堆叠显示。macOS 的 Dock 图标同时显示未读总数，读取该群后自动减少，全部读完清空。Dock 角标由 AppKit 绘制，不依赖通知权限。

点击图片、视频、GIF 或文件时，先保存到所选下载目录的当天文件夹，再交给系统默认应用打开。更换打开方式请在 Windows 或 macOS 的文件关联设置中选择；客户端不再弹出自带预览器。聊天内的图片缩略图和 GIF 展示仍保留，自动获取缩略图或仅保存附件不会打开外部应用。

聊天与聊天记录中的视频会按可见范围请求小封面（JPEG 最大 48 KiB），缓存后复用；不会为预览自动下载整段视频。视频卡片保持固定大小，封面加载不改变当前阅读位置。没有下载权限、旧服务端不支持或视频无法解码时保留播放卡片，点击仍按原方式下载并用系统应用打开。

语音直接在聊天中播放，再次点击停止；同时只播放一条。切换群、最小化、断开连接、撤销下载权限或正在播放的消息被撤回时会停止。自动预览与语音保存在独立缓存中，主动保存的附件进入所选下载目录的当天文件夹，播放不打开音乐播放器。

此包不包含 `wechat-relay`、Windows 微信适配器或 Python 解释器。演示命令仅供源码开发验证，不会启动真实微信转发服务。

界面不显示鼠标悬停提示。运行包不包含测试程序、测试日志、验收报告或截图；这些资料仅保留在源码工作区。
